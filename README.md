# Cleara

Cleara is a specified multichain financing and clearing protocol architecture for Creditcoin and Attestcoin.

Current status: **M1 verified, M2-M11 tested on testnet**. Current-head M11 passed the build/property gate, live Sepolia settlement, independent ERC20 payer validation, Attestcoin proof acceptance, and Creditcoin reconciliation in run `33614782209` at commit `c5f8eecd`. Cleara is not mainnet deployed, audited, or approved for production value.

The canonical operating truth is in `docs/canonical/GROUND_TRUTH.md`.
