# Cleara

Cleara is a specified multichain financing and clearing protocol architecture for Creditcoin and Attestcoin.

Current status: **M1 verified, M2-M10 tested on testnet, M11 implemented locally with a historical testnet PASS**. The historical M11 run exercised Sepolia settlement through Attestcoin and Creditcoin reconciliation; the stricter payer-validation changes on the current head still require a fresh live run. Cleara is not mainnet deployed, audited, or approved for production value.

The canonical operating truth is in `docs/canonical/GROUND_TRUTH.md`.
