# Judge-Path Evidence Package

Each run under this directory must identify:

- source and UI commit heads;
- target networks and environments;
- deployment addresses and constructor bindings;
- transaction, block, receipt, and finality identities;
- runtime bytecode hashes;
- independent state readbacks;
- UI deployment/source identity where applicable;
- evidence state and limitations.

Credentials, private keys, RPC secrets, and provider tokens are forbidden.

The current `REPORTED_EXTERNAL_RUN.md` is an operator intake record only. It is not independent proof and must not promote a claim to `LIVE_DEMONSTRATED` or `LIVE`.
